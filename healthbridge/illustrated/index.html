The problem02

Four records.
Four owners.

  • GP practice — EMIS Web or SystmOne holds the lifelong record
  • Hospital trust — its own EPR, its own login
  • Pharmacy — dispensing records, usually unlinked
  • National — NHS number, Spine, GP Connect: plumbing, not the record

The problem03

So what joins them?

Discharge summaries and clinic letters, arriving as documents.

A PDF is not a database row. Someone must read it, decide what it means, and code it — before the record knows anything at all.

The problem04

Six hands.
Two are manual.

  • Arrives →
  • filed as a document →
  • read and coded by a person →
  • filed to the record, by a person →
  • recall depends on the code →
  • clinician acts, days later

The problem05

What that costs

  • Coding lag — on paper, not in the searchable record
  • Recall misses — queries run on codes
  • Duplication — typed again elsewhere
  • Delay — an inbox result is an absent result
