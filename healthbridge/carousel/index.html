The solution

HealthBridge reads the
letter, proposes the code,
and asks a human.

1 · Ingest

Photo or PDF → structured fields. Discharge summary, clinic letter, lab result.

2 · Propose

Diagnosis, medication and action extracted, with a SNOMED CT code and a confidence.

3 · Confirm

A clinician accepts, edits or rejects. Only then does it enter the record.

The same engine, the whole visit

Six steps. One thread.

A letter is one round of this loop. HealthBridge runs the whole loop, so the next visit opens with the previous one already loaded.
